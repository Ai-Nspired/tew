## 3. Server tools (from the docs you put in the workspace)

- **Advisor** `openrouter:advisor` — consult a stronger model mid-generation; params `name`,
  `model`, `instructions`, `forward_transcript`, `stream`, `max_completion_tokens`, `reasoning`,
  `temperature`; several named advisors with one optional default; `tool_choice:"required"`
  forces a consultation; returns `{status, model, advice}`; cross-request memory on replay;
  consultations capped per request; recursion blocked.
- **Subagent** `openrouter:subagent` — delegate to a cheaper worker; sees only
  `task_description`; nested tools must be server tools (a client function is a 400 unless
  `inherit_functions`, Responses API only); `max_tool_calls` 1–25; returns
  `{status, model, task_name, outcome}`.
- **Apply patch** `openrouter:apply_patch` — V4A diffs, Responses API only;
  `create_file`/`update_file`/`delete_file`; OpenRouter validates and hands it back, the
  application applies; human-in-the-loop by design.
- **Web search** `openrouter:web_search` — engines `auto|native|exa|firecrawl|parallel|perplexity`;
  `max_results` 1–25, `max_uses`, `max_total_results`, `search_context_size`, `max_characters`,
  `allowed_domains`, `excluded_domains`; workspace can lock engine and domain lists.
  Pricing: Exa $0.007/request (deep $0.012, deep-reasoning $0.015), Parallel $0.001/$0.005,
  Perplexity $0.005, Firecrawl $0.005 + $0.0125/result, native passed through.
- **Evidence counters:** `usage.server_tool_use_details` → `tool_calls_requested`,
  `tool_calls_executed`, `web_search_requests`.
- Your own functions work at the top level of `tools`: the model calls, the application executes.

## 5. The workflow (note in `rebuild/tools/WORKFLOW.md`)

Domain awareness first — TEW's `POST /api/classify` returns `{domain, principles}`, and the NSM
layer holds per-domain principles, patterns and confidence. Then the searches as real-world
checks, several angles in one call. Then the results read back as tool output, not as prose.
Then the ceilings decide what may be asserted off what the searches established. Then the human,
who receives what was searched and what is still missing. Then saving — an open item, and a
`truth` concern, not a proxy one.

Open decisions recorded there: which searches count as the checks; what is saved at which stage;
whether the eitl is a human, an `advisor` consultation, or both.
